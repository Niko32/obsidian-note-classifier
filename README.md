# Note Classifier

Classify Markdown notes into a fixed list of tags using a decision model. The plugin writes the result to YAML frontmatter (`tags`) and leaves unrelated frontmatter fields and tags alone. Existing tags **from the configured list** are replaced on each classification; tags outside the list are preserved. No classification runs automatically: use a command to start it.

## Setup

1. Install and enable the plugin in **Settings → Community plugins**.
2. Open **Settings → Note Classifier** and enter available tags (one per line or comma-separated; `#` prefixes are optional).
3. Choose a **Tag combination**:
   - **Exactly one**: select the single best tag.
   - **Zero or more**: independently decide whether to assign each tag (a probability of at least 0.5 means yes).
   - **One or more**: independently decide each tag; if none qualify, use the single best tag.
4. Select which parts of each note the model receives: **File title** (basename without `.md`), **File frontmatter** (raw YAML, including any existing tags), and/or **File content** (body after frontmatter). At least one must be enabled. Large notes are sent in full; model context limits may cause a request to fail.
5. Choose a backend:
   - **Ollama (local)**: install [Ollama](https://ollama.com), run `ollama pull tev1`, and ensure the server is running at `http://localhost:11434`. The model name and base URL can be changed. Only decision models compatible with Ollama's `/v1/systemone` endpoint work; ordinary chat models do not.
   - **TypeSafe (Jev)**: get an API key at [TypeSafe](https://console.typesafe.ai/keys) and enter it in the settings. Uses `jev-latest` via `https://api.typesafe.ai/v1/systemone`.

Run **Classify current file** on an open Markdown note or **Classify all files** to classify every Markdown file in the vault. The batch command asks for confirmation, proceeds sequentially, and stops at the first error; already processed files remain changed. Check model output and back up important files before a large batch.

## Privacy and costs

Ollama uses a local server by default and needs no cloud connection. If you change the Ollama URL to a remote server, selected note data is sent there. TypeSafe sends only the selected note parts and tag names to TypeSafe when you run a classification command; TypeSafe may charge for requests. There is no telemetry. The TypeSafe API key is stored **unencrypted** in Obsidian plugin data (`data.json`); keep your vault configuration private. Only Markdown notes are modified. No note data is sent until you execute a command and (for batch classification) confirm it.

```sh
npm ci
npm run build
npm run lint
npm test
```

Obsidian 1.5.7 or later is required. `main.js` is generated by the build and should not be committed.
